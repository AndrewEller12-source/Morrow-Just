# Design tokens

Keep agreed visual values shared between design and code here once selected. Use semantic names such as `text.primary`, `status.warning`, `space.cardInset`, and `type.noteBody`. Record units and target display context.

No values are approved by this scaffold. After the first HUD design review, choose a small machine-readable format and document the matching Illustrator swatches/type styles. Keep one source of truth with an explicit export or conversion step.
