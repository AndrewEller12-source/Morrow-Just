# Design workspace

Design connects brand identity, the HUD system, and implemented behavior. Existing MORROW originals stay in their current folders; only selected assets enter this public repository.

| Location | Purpose |
| --- | --- |
| [brand/](brand/README.md) | Selected logo exports, brand rules, and source/version references |
| [hud/](hud/README.md) | Proposed Illustrator workspace, components, screen states, and handoffs |
| [tokens/](tokens/README.md) | Agreed colors, spacing, type roles, and other visual values |
| [flows/](flows/README.md) | Interaction sequences and acceptance criteria |

Illustrator holds editable visual masters; GitHub holds implementation, selected exports, specifications, and review history. Store a native `.ai` file in Git only after choosing its canonical home and checking size, linked assets, and sharing rights. No Illustrator document or visual design is created by this foundation.

A design handoff identifies the source revision, named artboards, exports, component/state names, token changes, behavior, and known optical limitations. Link it in the issue and pull request.
