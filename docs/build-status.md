## Proposed sequence

| Step | Deliverable | Evidence required to close |
| --- | --- | --- |
| 0. Locate source and inventory | Existing companion/HUD/frame paths; exact owned hardware | Inspect source; identify host, parts, revisions and cables |
| 1. Resolve optical interfaces | Matched kit BOM, driver input, power, cables and drawings | Manufacturer documentation and selected host connection |
| 2. First optical note | Fixed short note and corner targets on actual optics | Recorded setup and observed readability; visible corners at selected eye position |
| 3. USB orientation | Timestamped orientation with recenter and disconnect states | Real stream, reconnect checks, recorded failures; orientation is not position |
| 4. Complete note experience | Create/edit/display/resize/dismiss locally | Repeatable UI checks and real display updates; measure latency |
| 5. Frame integration | Adjustable carrier and cable route based on actual parts | Physical fit, folding, cable clearance and weighted comfort evidence |

Local UI work can progress while optical information is obtained, but cannot close the physical optical milestone. Camera input follows a reliable mouse/keyboard path. Audio, portable power, radio, and custom PCB work remain later stages.

3. Existing companion, HUD, firmware, frame files, and additional Flux notes.

Do not convert a candidate BOM entry into an owned or tested part without evidence.
